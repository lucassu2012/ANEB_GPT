# 智能体网络诉求到 ANEB 的产品映射

> 日期：2026-07-16  
> 输入：Codex 会话 `019f4b68-e951-78b0-a670-2f61c8748352` 的结论  
> 状态：测量架构已落地到 Token、AI 实时与网络综合三类可执行 Profile；候选 enhanced 数值仍未替代 D-37 的 provisional v1 目标

## 1. 反方观点与边界

智能体业务不必然造成持续大带宽。文本、代码和控制型 Agent 的首要风险通常是交互尾时延、截止时间违约、长连接中断和多步骤任务失败；大带宽主要由实时视觉、远程操作、文件同步以及多模态上传触发。

ANEB 因此不把“峰值 Mbps”当成统一答案，也不把 5QI 的 PDB/PER 当成应用端到端 SLA。正式结论仍限定为终端到 ANEB 自建探针节点的应用层路径。第三方模型推理、工具执行和渲染时间不进入网络评分。

## 2. 五类业务原型

| 原型 | 主要行为 | ANEB 状态 |
|---|---|---|
| A 后台异步 | 长驻连接、通知、状态同步、弱覆盖恢复 | 后续 `background_continuity` Profile |
| B 交互控制 | 指令/状态、低时延反馈、多步骤工具流 | Token 标准 Profile 先覆盖；后续独立 `agent_control` |
| C 实时语音 | 双向小包、低抖动、截止时间敏感 | `ai_realtime_simulation` |
| D 实时视觉/远程操作 | 持续上行、突发反馈、强尾时延约束 | 后续 `realtime_visual` Profile |
| E 文件同步 | 大对象上传/下载、断点续传、额外字节控制 | Token 多模态与压力 Profile 先覆盖 |

## 3. 立即纳入 Profile v2 的测量原则

1. **三态结论**：`PASS / FAIL / INCONCLUSIVE`。样本不足、必需指标缺失或 run 无效时不得给通过分。
2. **缺失值语义**：显示不可用，永不把缺失强制为 0；评分为 `null`，保留原始证据。
3. **应用 RTT**：客户端到真实 ANEB 探针入口的请求往返；不包含模型、工具或渲染耗时。
4. **截止时间可靠性**：`deadline 内收到的有效消息数 / 已发送消息数`，与平均 RTT 分开。
5. **有效丢失率**：未收到或虽收到但错过业务截止时间的消息数 / 已发送消息数。UDP、TCP/QUIC 和应用请求失败必须分开命名和分母。
6. **负载时延增量**：同一路径负载阶段 RTT 与空闲基线的差；不能只显示负载 RTT 绝对值。
7. **持续速率**：优先报告窗口分位数与达标窗口比例；`P10 goodput` 表示至少 90% 的采样窗口不低于该速率。
8. **逻辑会话连续性**：允许传输层重连，但任务、工具调用、序列号和结果不得丢失或重复提交。
9. **时钟边界**：无可信双端时钟时不报告单向时延，也不使用 `RTT/2` 冒充。
10. **Trace ID 归因**：客户端发起、探针收到、探针发回、客户端收到四阶段留痕；固定仿真测试与真实生产验证分开。

## 4. 指标增量映射

| 新增/强化指标 | 业务意义 | 首个落点 | 评分角色 |
|---|---|---|---|
| 控制消息 300ms 截止时间可靠性 | 交互指令是否及时生效 | `agent_control` | 必需 + 门控候选 |
| 多步骤工作流网络无故障完成率 | 单次失败如何放大为任务失败 | Token/控制 | 必需 + 门控候选 |
| 负载下 RTT 增量 | 排队拥塞是否破坏交互 | 网络综合 | 必需 |
| 路径切换恢复 P95 | 蜂窝/Wi-Fi 切换是否中断任务 | 后台连续性 | 必需 + 门控候选 |
| 网络诱发重复副作用 | 重试是否重复提交工具/支付等动作 | 控制/连续性 | 零容忍门控候选 |
| 断点续传完成率与额外字节率 | 弱网恢复成本 | 文件同步 | 必需 + 诊断 |
| 150ms 内媒体包比例 | 语音包是否仍有业务价值 | 实时语音 | 必需 |
| 网络诱发流式停顿 P99 | Token/语音输出的连续性 | Token/实时语音 | 必需 |

## 5. 候选 Enhanced 目标集（未批准替换 D-37）

这些值来自参考会话，先冻结为候选 `agent-network-enhanced-targets-v0-draft`，不得用于当前正式评分：

- 交互控制 RTT：P95 ≤ 100ms，P99 ≤ 200ms；300ms 截止时间可靠性 ≥ 99.9%。
- 10 步工作流网络无故障完成率 ≥ 99.5%。
- 路径迁移恢复 P95 ≤ 1s；完整重连候选上限 ≤ 2s。
- 80% 负载下时延增量：P95 ≤ 30ms，P99 ≤ 100ms；增强档候选 20/50ms。
- 实时语音：RTT P95/P99 ≤ 80/150ms；有效丢失率 ≤ 0.5%；IPDV P95 ≤ 20ms；150ms 内有效媒体包 ≥ 99.5%。
- 实时视觉忙时上行 goodput P10 ≥ 10Mbps。
- 文件同步 goodput P10：上行 ≥ 10Mbps、下行 ≥ 20Mbps；100MiB 上传/下载基线 ≤ 90/45s；断点续传完成率 ≥ 99.5%，额外字节率 ≤ 5%。
- 网络诱发重复副作用必须为 0。

D-37 当前 Token、实时交互和网络综合三套 provisional v1 门限不变。若采用上述 Enhanced 数值，必须由 Product Owner 批准并新增 target/score policy 版本。

## 6. 样本与置信度

- 尾部分位数必须同时显示样本量。若希望尾部约有 100 个观测，P95/P99/P99.9 粗略需要约 2,000/10,000/100,000 个样本。
- 零失败不等于零风险。单侧 95% 上界低于 1%/0.1%，约需 299/2,995 次独立任务且零失败。
- 当前快测无法支撑 99.9% 可靠性通过结论时，应输出 `INCONCLUSIVE`，不能用短样本给出高可靠性承诺。
