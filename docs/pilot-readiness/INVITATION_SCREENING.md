## 邀请正文

［FRAME｜LOW］以下是建议话术，不是市场需求证据：

你好，我们正在为已发布的 ANEB Prototype 0.1 寻找一位自愿参与者，看看它的报告能否帮助技术团队比较同一固定任务在 Baseline、Slow、Unstable 三种合成条件下的流式响应，并让另一位操作者复核结果。

本次拟使用同一固定包、一个获准的站点，交付运行证据、离线报告和一次结果解读。我们想先了解：你希望这份报告支持什么具体决定？例如，是否适合纳入你们的内部应用层测试记录，或用于复核响应时间、停顿和完成情况。

它不测试真实第三方 App，不诊断无线网络或运营商问题，也不承诺高分、性能提升或服务等级。失败和取消会如实记录。已验证环境是 Windows x64 电脑、Huawei P40 Pro 及经许可且可互访的局域网；证据发送到选定本地电脑节点，接收人和保管方式需先确认。

如果这个用途与你相关，是否愿意先回答约五分钟的适配问题？这五分钟仅用于筛选；若双方之后同意执行，还需另约时间完成安装、一次 Quick（三次运行）、一次 Acceptance（九次运行），以及结果导出和复核；具体安排另行确认。

不适配就到此停止，不需要提供账号密码或 API key。这不是报价，也不承诺免费长期服务；任何执行安排与服务条件都须另行确认。

## 筛选脚本：只提问，不启动产品

［FRAME｜LOW］主持人开场：“先确认适配，不做演示、不收凭据、不要求当场安装；你可以不回答或停止。本次只记录经你同意的必要答复，不默认录音。”五分钟是讨论结构，不是完成时限。

| 话题 | 逐字问题 | 最小记录及停止规则 |
|---|---|---|
| 用途 | 你希望报告支持哪一个具体决定？谁会使用？只比较固定合成任务是否足够？ | 记实际决定。若需要真实 App/模型排名、无线故障归因、运营商 SLA 或保证高分，标不适配并结束，不改措辞成交。 |
| 环境 | 是否有获准使用的 Windows x64、P40 Pro，以及经场地允许且可互访的局域网？谁确认安装和必要入站权限？ | 记有/无/UNKNOWN及授权角色，不索取 IP 或凭据。缺条件就暂停安排，不关闭防护、不改变 Windows 网络信任类别，不外推其他设备兼容性。 |
| 自愿与复核 | 参与是否自愿？是否接受失败、取消和空值原样呈现，以及证据通过不代表测量成功？能否安排另一位操作者复核？ | 记录明确同意/拒绝/待确认。拒绝即结束；没有复核者留待补，不编造人员或日期。 |
| 数据 | 谁的本地节点接收证据？谁可收到报告、谁保管手机/节点/导出/备份？保存多久、何时复核删除？能否在执行前确认？ | 只记角色与约定，不收实际证据。接收/保管不明暂停；删除一处不会撤回其他副本，没有自动删除或不可恢复擦除承诺。 |
| 时间与范围 | 你和复核者有哪些可用时段？单站点、固定包、一次交付与解读是否适合？还有什么内部审批？ | 记录参与方时间，不承诺我方响应/完成时限。报价、长期免费、额外站点、定制或 SLA 转服务条款确认，不现场承诺。 |

收尾：“按你的实际答复记录为适配待确认、待补条件或不适配。今天不会启动试点、联系其他人或收款；可推进时先确认参与授权、数据交接和执行安排。”
